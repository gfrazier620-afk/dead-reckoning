# Dead Reckoning

A tile-based zombie survival game — build a shelter, gather resources, and rescue survivors before the horde gets you.

## Status: Milestone 1 — Foundation

- Tile-based map with collision
- Controllable player (arrow keys / WASD)
- Camera follows player around the map

## Coming next

- Resource gathering (trees, cars, scrap piles)
- Shelter building menu
- Day/night cycle with zombie spawns
- Survivor rescue system

## Running it locally

Just open `index.html` in a browser — no build step, no server required. Phaser loads from a CDN.

## Running it via GitHub Pages

Enable GitHub Pages on this repo (Settings → Pages → deploy from `main` branch, root folder), then visit the generated URL.

## Tech stack

- [Phaser 3](https://phaser.io/) for the game engine
- Vanilla JS, HTML, CSS — no build tools
